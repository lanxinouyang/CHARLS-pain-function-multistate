# Data availability

This repository does not contain or redistribute individual-level data from the China Health and Retirement Longitudinal Study (CHARLS).

The analyses in this study were conducted using CHARLS data from the 2011, 2013, 2015, 2018, and 2020 waves.

Researchers interested in reproducing the analyses should obtain the required CHARLS datasets directly from the official CHARLS data platform and comply with the applicable data-use requirements.

Only analysis code and documentation are provided in this repository.
